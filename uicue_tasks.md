# Задачи и DevFlow для сервиса UICue (A/B Тестирование)

## 1. Инфраструктура и Авторизация
- [ ] Проверить стабильность запуска приложения `UICue`.
- [ ] Настроить и протестировать авторизацию через единый сервис **UXUID**.
- [ ] Убедиться, что после авторизации происходит корректный редирект на стартовую страницу.

## 2. Интерфейс онбординга (Добавление сайта)
- [ ] Разработать страницу «Добавить сайт и запустить A/B тест».
- [ ] Добавить две основные плашки/кнопки:
  - **Импортировать из текущих**: Выбор сайта из уже существующих проектов пользователя (данные запрашиваются из `UXUID` или общего хранилища).
  - **Добавить новый**: Ввод URL и создание проекта с нуля.

## 3. Проектирование DevFlow (Путь пользователя)
1. **Инициализация**: Авторизация -> Выбор/Создание сайта -> Кнопка «Новый A/B тест».
2. **Настройка гипотезы**:
   - Привязка теста к конкретной гипотезе из хранилища `UXUID` (или импортированной проблемы из `RovUI`).
   - Настройка базовой (А) и тестовой (B) вариаций. (Для версии B могут применяться правки через `UXGen`).
3. **Маршрутизация трафика**: 
   - Настройка пропорций распределения трафика (например, 50% на 50%).
   - Выбор сегмента аудитории (по устройствам, географии и т.д., если нужно в MVP).
4. **Интеграция**:
   - Генерация единого JS-сниппета (скрипта) для интеграции на сайт клиента.
   - Для внутренних проектов (сгенерированных в нашей экосистеме) скрипт должен инжектиться автоматически.
5. **Запуск и Мониторинг**: Старт теста, сбор данных в реальном времени.

## 4. Набор функций и метрики (Что будем измерять)
Для качественного A/B тестирования нужно реализовать сбор и анализ следующих метрик:

### Ключевые метрики (События):
- **Макро-конверсии**: Успешные регистрации, покупки, отправки лид-форм.
- **Микро-конверсии**: Клики по CTA-кнопкам, переходы по конкретным ссылкам, добавление в корзину.

### Поведенческие метрики:
- Показатель отказов (Bounce Rate).
- Средняя продолжительность сессии / Время на странице.
- Глубина скроллинга страницы.

### Аналитический функционал:
- **Дашборд сравнения**: Графики конверсии вариации A против вариации B в реальном времени.
- **Статистическая значимость**: Автоматический расчет p-value. Индикатор того, можно ли доверять результатам и пора ли останавливать тест.
- **Логирование ошибок**: Трекинг того, не сломал ли патч (вариация B) логику сайта.
